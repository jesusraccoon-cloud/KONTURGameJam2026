# Меню: кнопки «Продолжить» и «Новая игра»

Инструкция, как в сцене меню сделать кнопку загрузки последнего сохранения (**Продолжить**) и **Новую игру**.
Опирается на уже готовую систему сохранений (`SAVE_SYSTEM.md`).

Коротко:
- **Продолжить (Continue/Load)** — читает `save.json` с диска и загружает сцену на последнем чекпоинте.
- **Новая игра (New Game)** — стирает сейв и запускает игровую сцену с нуля.
- Кнопку «Продолжить» можно автоматически гасить, если сейва ещё нет.

---

## Что уже готово в коде

В `SC_SaveManager` есть публичные методы (их вешаем на кнопки):

| Метод | Что делает |
|---|---|
| `ContinueFromDisk()` | Прочитать сейв с диска и перейти в сохранённую сцену на последний чекпоинт |
| `NewGame()` | Стереть сейв и загрузить игровую сцену заново |
| `HasSave()` → bool | Есть ли сейв на диске |

Плюс вспомогательный скрипт **`SC_ContinueButton`** — сам делает кнопку «Продолжить» неактивной, если сейва нет.

---

## Шаг 0. Build Settings (обязательно)

Открой **File → Build Settings** и убедись, что в списке **Scenes In Build** добавлены **обе** сцены:
меню и игровая. Без этого `LoadScene` по имени не сработает.

---

## Шаг 1. SaveManager в сцене меню

1. Создай пустой объект, назови `SaveManager`, добавь компонент **`SC_SaveManager`**.
2. Заполни только одно поле:
   - **Gameplay Scene Name** → точное имя игровой сцены (как в Build Settings). Нужно для «Новой игры».
3. Остальное (Player / Monster / Checkpoints) в меню **оставь пустым**.
4. Сними галочку **Enable Debug Reload Key** (чтобы клавиша `N` ничего не делала в меню).

---

## Шаг 2. Кнопка «Продолжить»

1. Создай UI-кнопку: **GameObject → UI → Button** (назови `ContinueButton`).
2. Выдели кнопку → в инспекторе найди компонент **Button → On Click ()** → нажми `+`.
3. В новый слот перетащи объект `SaveManager`.
4. В выпадающем списке выбери **`SC_SaveManager → ContinueFromDisk ()`**.

**Автогашение кнопки, когда сейва нет** (рекомендуется):
1. На том же `ContinueButton` добавь компонент **`SC_ContinueButton`**.
2. Поле `Button` подставится само.
3. (Опц.) в `Hide When No Save` можно кинуть объект, который надо **прятать** при отсутствии сейва
   (например саму кнопку). Если оставить пустым — кнопка просто станет серой/некликабельной.

---

## Шаг 3. Кнопка «Новая игра»

1. Создай UI-кнопку `NewGameButton`.
2. **Button → On Click ()** → `+` → перетащи `SaveManager`.
3. Выбери **`SC_SaveManager → NewGame ()`**.

> `NewGame()` стирает `save.json` и грузит сцену из **Gameplay Scene Name**. Убедись, что имя задано (Шаг 1).

---

## Шаг 4. (Опционально) Подтверждение перед «Новой игрой»

Если сейв есть, «Новая игра» его сотрёт. Чтобы не потерять прогресс случайно:
- сделай маленькое окно-подтверждение «Начать заново? Прогресс будет удалён» с кнопками **Да/Нет**;
- кнопку **Да** повесь на `SC_SaveManager.NewGame()`;
- открывать окно можно только если `HasSave()` вернул true (иначе сразу `NewGame()`).

Для джема можно пропустить и вешать `NewGame()` напрямую.

---

## Как это работает под капотом

1. **Продолжить:** `ContinueFromDisk()` читает `save.json`, ставит флаг «применить после загрузки»
   и грузит сцену из сейва. В игровой сцене `SC_SaveManager` (уже настроенный по `SAVE_SYSTEM.md`)
   через кадр восстанавливает позицию игрока, монстра, стадию и «использованные»/состояние объектов.
2. **Новая игра:** `NewGame()` удаляет сейв и грузит игровую сцену с нуля — все объекты в исходном состоянии.

Файл сейва: `%userprofile%/AppData/LocalLow/<Company>/<Product>/save.json`
(`<Company>`/`<Product>` — из **Project Settings → Player**).

---

## Проверка

1. Запусти игровую сцену, дойди до чекпоинта (появится сейв на диске).
2. Выйди в меню (или перезапусти игру).
3. Кнопка **Продолжить** активна → нажми → должно закинуть на последний чекпоинт с сохранённым состоянием.
4. **Новая игра** → должна начать с самого начала (сейв стёрт, кнопка «Продолжить» снова серая).

> Если кнопка «Продолжить» всегда серая — значит сейва ещё нет: сначала дойди в игре до чекпоинта.
> Если по нажатию ничего не грузится — проверь Build Settings (Шаг 0) и `Gameplay Scene Name`.
